# JobFinder Python API

API du projet **JobFinder**.

Cette API permet de proposer des recherches de jobs contextualisées selon le profil utilisateur.  
Objectif: envoyer directement des offres adaptées (par exemple junior vs expert), au lieu de proposer des postes non pertinents.

## Lancer le serveur

Depuis le dossier jobfinder-python (1er niveau):

```bash
uv run src/jobfinder-python/main
```

## Documentation Swagger

Si le serveur tourne, la documentation Swagger est disponible ici:  
[http://localhost:8000/docs](http://localhost:8000/docs)
